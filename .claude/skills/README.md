# Design skills

These skills teach Claude how to design and animate interfaces well. Claude picks
them up automatically when working in this repo.

They come from Emil Kowalski's skills collection:
https://github.com/emilkowalski/skills (copied unchanged from commit `a81dbca`).
They are MIT licensed. See `LICENSE` in this folder.

Included: emil-design-eng, animate, review-animations, improve-animations,
find-animation-opportunities, remove-animations, animation-performance,
animation-vocabulary, apple-design, pick-ui-library, prototype, mobile-native,
break-ui.
