# Bibelabend

Handy-Web-App als Ergänzung zur WhatsApp-Gruppe des Bibelabends.

- **Treffen:** wer kocht, wer ist dabei, wer kann nicht
- **Themen:** Themenwünsche sammeln, mit „Ich auch“ abstimmen
- **Gebet:** Gebetsliste mit Vornamen, Anliegen und „Erhört“-Häkchen

Jede Person hat eine eigene Farbe. Jeder kann nur seine eigenen Einträge löschen.

## Stand

Testversion. Die Namen sind Beispiele (in `index.html` unter `PEOPLE` ändern).
Einträge werden noch nur auf dem eigenen Handy gespeichert. Ein gemeinsamer
Online-Speicher kommt als nächster Schritt.

## Auf den Homescreen

- **iPhone:** Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“
- **Android:** Seite in Chrome öffnen → Menü ⋮ → „App installieren“
